# 0004 预留期权化（rera）表决材料 —— 判词：中性归档，不转正

数据源：run 34674525812（bench v9 六臂 + repro-patched VERDICT，均 release，同种子 CRN）。

## 读数

- **机制生效证明**（repro-patched rera_readings）：Y3 turn=60 近满位（h=5）单回合，智训练分
  base=499 → rera=**513**（+14，正是 r 40→10 使惩罚项缩水的理论方向）；该局面位次未变。
- **整局判定**（bench F vs A）：140 局 mean_score/train/rests/自选赛 **逐位全等 64271.5|56.70|4.10|0.29**
  ——r 缩差在真实对局分布里从未跨过任意决策的位差。

## 判词

1. **0004 判「中性」，归档不转正**（开关保留、默认关=逐位不变，符合 gate 誓言）。
2. 结构原因：期权化的原始动机是给上限悬崖纠偏（抬升期望该有剩余空间），而 **0001/0005 的钳制
   已把 h=0 悬崖清零**——r 的残余影响只在 h>0 内区，量级（±15）远小于 140 回退门与动作间位差。
   两头一挤，期权表在已修基础上没有可咬合的空间。
3. 推论修正（报告 §5 的「0004 候选」预期）：cap 抬升期望的**价值不在 r 缩放**，若再挖此方向，
   唯一未测的形态是给 `status_gain` 加 `cap_slack`（把溢出增益折进未来抬升的实分）——列为库存，
   不立项（现证据链里它和已判负的 vcurve 一样，属于给同一枚硬币两面调参）。
4. 与主人三条的对应：(1) 软化门限=0001 转正✔；(2) 结构性偏置=维持不动（真实评分规则）✔；
   (3) 超限收益建模=经 0004 实测后判「钳制即终态」✔。本案三条全部收口。
