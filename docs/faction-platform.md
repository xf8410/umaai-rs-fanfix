## 1. 谱系（帝国侧·裁判所线）

- **保守派 the Faithful**：教义完美，只净化异端不改制度 → 对应：纯镜像+只报 issue。
- **激进派 Radicals**（Amberian Schism 后分裂）：
  - **单一至高派 Monodominants**：一条正确路线推平一切 → 对应：全量翻默认、fork 面目全非。**禁止**。
  - **桑彩派 Xanthites**：渐进改良、改一步验一步 → **本 fork 当前路线**。
  - **文德里特军权派**：弃辩论、上武装长线 → 对应：放弃单点 patch，转重搜索/NN 管线。保留选项。
- **大叛教时代**：
  - **修正主义者 Revisionists（Thezmalien）**：「教义偏离根本信纲，回到真义」，议会路线 → **对具体病灶的立场**：用户定调「上限硬门限有问题，得软化」= 党纲第一条；红测试=经文。
  - **盖勒派净化者 Gellerites**：烧掉一切可疑物 → 推倒重写估值层。**禁止**。
  - **玛洛里党**：烧书灭知 → 「废掉手写估值层」的极端形态。不采。
- **伊瑟莱安圈 Isitarian Circle**：廷内秘密改革，借帝国之手颁新法 → **对上长期路线**：所有证据链按可提上游 PR 的形态书写。
- **混沌/泰伦**：改信异端引擎/外源重构 → 项目边界，不碰。

## 2. 一句话主定义

**本仓 = 激进派的桑彩派分支，对病灶持修正主义者立场，对上游走伊瑟莱安路线。**
底线：设备端可用（帝国不塌）；手段：配置门控 + 证据转正，永不一道政令改天换地。

## 3. 议案接口（治无头苍蝇的路由）

```text
Bill（每条新现象/新改动 = 一个议案）:
  classify()  → 病厅三选一：
                ① 收费错误 bug（重复收费、正值被吞）→ 纠错 patch + 单元红测
                ② 建模缺失（上限抬升期权、恢复地平线未入分）→ 建模 patch
                ③ 定价扫描（体力价、PT 价、罚分权重）→ token 矩阵 A/B
  gate()      → 桑彩派誓言：新行为必须配置门控、默认关、逐位不变
  evidence()  → repro 红测试 + CI 同种子 A/B（行为列优先：打分休息数/train占比；
                整局分对 margin 级修复不敏感——ab-results-rclamp.md 教训）
  vote()      → 正=转正进 preset；中性=留档凭正确性转正；负=回退归档
  tithe()     → 成熟议案打包上游 PR（伊瑟莱安：让正统的手颁布改革）
```

**执行序恒为：定性 → 立项（对号入座） → 门控 → CI 经文 → 表决（用户=审判官长终裁） → 帝国税。**
新现象进来第一问永远是「归哪个厅」——归完厅才知道走哪条管线。
